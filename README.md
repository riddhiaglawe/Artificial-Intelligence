### 📘 Project Description  

A web-based AI Expert System designed for industrial equipment maintenance and predictive analysis.  

The system analyzes motor conditions using rule-based inference, detects faults, visualizes decision paths, and generates maintenance suggestions with downloadable reports.

---

### ⚙️ Features  

- 🔍 Motor Condition Analysis  
- 🧠 Rule-Based Expert System (IF–THEN logic)  
- 📊 Explainable AI (Rule evaluation display)  
- 🔄 State-Space Search Visualization  
- 🎯 Intelligent Maintenance Suggestions  
- 🧪 Sensor Data Simulation  
- 📄 PDF Report Generation  
- 🗂 Maintenance Logs Storage  
- 🌐 Interactive Dashboard  

---

### 🧠 System Workflow  

Input Data → Knowledge Base → Inference Engine → Output Decision  

---

### 📚 Example Rules  

- IF Temperature > 85 AND Vibration = High → Bearing Wear  
- IF Oil Level = Low → Refill Lubrication  
- IF Battery Status = Low → Replace Battery  
- IF Vibration = High AND Noise = High → Shaft Misalignment  
- IF Temperature > 90 → Critical Overheating  

---

### 🔄 State-Space Representation  

[Initial State] → [Condition Check] → [Fault Detection] → [Solution]
