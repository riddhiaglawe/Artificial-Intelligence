# Practical 12 – AI Tool (Image Enhancement)

## Aim
To enhance image quality and resolution using AI-based tool Let’s Enhance.

## Objective
- Understand AI in image processing  
- Improve image quality and resolution  
- Compare original and enhanced images  

## Theory
AI-based image processing uses deep learning techniques to enhance images by:
- Increasing resolution (upscaling)  
- Reducing noise  
- Improving sharpness and colors  

## Example
Low-quality image → Enhanced high-quality image  

## Algorithm
1. Upload image to tool  
2. Apply enhancement  
3. Download result  
4. Compare output  

## Conclusion
AI tools like Let’s Enhance improve image quality efficiently and automatically.
